# 功能体验流程

## 准备环境

```bash
bundle config set --local path vendor/bundle
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/dev
```

登录账号：

```text
demo@launchpulse.test / password
```

## 1. 打开站点详情

登录后选择任意站点。详情页提供页面预览、访问数据、优化建议、实验、事件流和版本记录。

点击 `公开预览` 可以查看访客实际访问的已发布版本。后台预览则展示当前草稿。

## 2. 分析页面

点击 `分析页面`。分析完成后，优化建议会按页面区块显示。

每条建议包含当前问题、调整依据、建议字段和重点观察指标。打开字段变化可以查看修改前后的具体内容。

## 3. 预览和应用建议

点击 `预览改动` 查看调整后的页面效果。该操作不会保存内容。

确认后点击 `应用到草稿`。如需恢复原内容，可以在建议卡片中点击 `撤回`。

## 4. 创建实验

点击 `创建对照实验`。系统会固定保存原始版本和优化版本，并为两个版本分配流量。

同一区块已有实验时，新的实验会被阻止，直到现有实验结束并处理完结果。

## 5. 产生转化事件

打开公开站点并提交表单，或者选择商品、课程方案。后台会记录访客、区块、实验版本和转化事件。

调试模式会在公开页显示访客编号和版本分配：

```bash
DEMO_DEBUG=true bin/dev
```

## 6. 查看实时数据

返回后台查看页面浏览、独立访客、转化率、来源、设备、事件流和实验结果。

需要快速补充数据时，可以在 `测试工具` 中运行访客模拟。模拟任务通过后台队列执行，完成后页面会陆续更新。

## 7. 结束实验

点击 `结束实验` 后，选择采用原始版本或优化版本。所选内容会写入草稿，实验结果会保留在记录中。

## 8. 发布和恢复

点击 `发布` 生成新版本。版本记录支持：

- 对比已发布版本与当前草稿；
- 查看新增、删除和修改的区块；
- 查看完整版本数据；
- 恢复历史内容并发布为新版本。

更详细的操作说明见[功能体验指南](../docs/demo-guide.md)。
